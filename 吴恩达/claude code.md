
### 模式

三种核心交互模式，可通过Shift + Tab 循环切换

1. Default（默认模式）最安全模式。Claude在进行文件编辑、删除或执行shell命令前会询问，适合敏感工作 `? for shortts`
2. Auto（自动接收模式）高效率模式。Claude可直接写入文件无需确认，但仍会就shell命令询问，适合快速代码生成和日常迭代。 `accept edits on`
3. Plan（计划模式）：规划模式。Claude仅使用只读工具分析代码，生成行动计划供用户批准，适合复杂重构和探索代码库 `plan model on`
